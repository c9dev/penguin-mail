Penguin Mail apt repository

Penguin Mail is a Gmail client for GNOME. This repository holds its Ubuntu packages for amd64, signed with the key below.

Add it

sudo curl -fsSLo /usr/share/keyrings/penguin-mail-archive-keyring.gpg \
  https://c9dev.github.io/penguin-mail/penguin-mail-archive-keyring.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/penguin-mail.sources \
  https://c9dev.github.io/penguin-mail/penguin-mail.sources
sudo apt update && sudo apt install penguin-mail

Installing the .deb from the releases page adds these two files for you, so sudo apt upgrade brings each new version after that.

The signing key

penguin-mail-archive-keyring.asc, fingerprint FE3C 3B6E 699A F939 DC46 70DC F3A8 5303 5C3E 2B8E.
